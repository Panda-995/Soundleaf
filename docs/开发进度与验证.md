# 声页 v0.1.0 · 开发进度与验证

日期：2026-09-15。

## 已交付

React + TypeScript 前端、FastAPI 后端、SQLite 持久化队列、FFmpeg 音频处理、MiniMax 与兼容语音接口适配、独立 AI 分析适配，以及源码 Docker 部署配置。九个工作页面已接实际 API。

容器以普通 UID/GID 运行，可映射 /data 和 8780 端口，移除 Linux capabilities，不需要特权、设备或 Docker socket。部署者通过普通 NAS 账户或文件夹 ACL 准备数据目录。

## 核心约定

1. 原文与朗读脚本分开保存。AI 输出索引明确的建议，只有用户采纳保存后才改变脚本参数。
2. 每次修改增加修订号，任务捕获文本与服务配置。旧任务结果保留为版本，仅修订号仍匹配时成为当前成品。
3. 缓存包含文本、引擎、模型、音色和生成参数。只改停顿会复用语音片段并重新拼接。
4. 网络异常或请求中途退出时进入“结果待确认”，不自动重发可能已计费的语音请求。待处理任务重启后保留。
5. 导出保存固定版本清单。后续修改章节不会改变已提交导出的内容，旧版本需显式允许导出。
6. 暂停队列等当前任务完成；取消在处理边界生效，不能撤回已发送给服务商的请求。
7. 当前仅支持一个实例、一个 worker，不支持多容器共享数据库。

## 本地验证

后端 tests/test_studio.py 共 25 项测试，覆盖：

- 认证、CSRF 与受保护下载。
- TXT 编码、原文保留、切段文本覆盖、EPUB spine 顺序、脚本清理及 ZIP 路径拒绝。
- 修订冲突、章节选择、重复生成去重、缓存复用、局部重做、Range 206、MP3/WAV 和 ZIP 顺序。
- 旧修订不覆盖当前脚本、密钥加密与恢复。
- AI 建议格式验证与原文不变。
- AI 优化分段：本地按引号边界细分为对白/叙述单元后由 AI 结合上下文标注说话者（单元编号协议，不回传原文）；引号内不一定是台词——拟声词、音效、名称类引号由模型标为旁白并与相邻叙述融合，纯标点衔接不独立成段；覆盖多角色同段对话分离、混组本地拆分、旁白恒为旁白、无效分组的逐单元回退、超长单元切分与原文逐字符校验。
- AI 分析：输入带相邻上下文（prev/next 摘要），提示词要求识别全部角色并排除非对话引号；逐项异常降级（无效情绪→默认、越界语速→夹取、编造音色→清空），不再整批失败。
- 情绪与合成：21 种情绪风格映射到服务商情绪枚举与语速/音高/音量组合，结巴以合成期文本变换实现；兼容接口自动降级为语速倾向，不再阻断生成。
- 语音合成：角色片段在合成时按引号边界拆分，对白用角色音色、叙述回落旁白音色；无引号文本在合成端强制使用书籍默认音色（AI 误标叙述为角色也不会串音）；书级角色表（cast）跨章节持久化"说话者→音色"绑定，说话者名称归一化合并变体，章节保存与生成时自动同步；服务端瞬时拒绝（1002/1026/1027、429、5xx）自动退避重试且不产生重复计费，失败报错带片段序号与文本预览。
- 界面：明暗双主题（语义令牌 + 侧边栏切换 + 本地记忆）、克制动效系统（页面进入、对话框/Toast、播放呼吸、背景低速光晕），全部尊重 prefers-reduced-motion；试听页可点击任意段落跳转到对应音频位置。
- 重启恢复、不确定请求保留、播放进度书籍归属和边界。
- 重试不能与本章正在执行的同类任务重复。

Python 静态检查和前端生产构建通过。

浏览器测试由 tests/ui_fixture.py 提供隔离语音与 AI 测试服务，scripts/browser-smoke.cjs 完成默认账户登录、首次登录强制改密、配置、上传、后台生成、播放、修订和 ZIP 下载。九页检查 1536、1024、390 像素宽度，无横向溢出和页面运行错误。AI 导演页验证"AI 优化分段 → 预览 → 采纳"全流程，采纳后逐字符校验原文完整，并确认"AI 分析本章"按采纳后的分段逐段返回建议。

本地证据保存在 output/runtime/browser-verification.json 与 screenshots/，不进入部署包，避免测试账户和测试配置进入正式部署。测试声音为合成信号，不代表中文发音或情感质量。

## 未验证及限制

- 开发机没有 Docker 引擎，未实际构建/启动容器，未实测 NAS ACL、非 root 容器重启持久化和 amd64/arm64 启动。
- 没有真实服务商密钥，未进行付费 TTS/AI 调用，不能保证具体模型、音色在用户账号中可用。
- 未完成百万字长篇压力测试、数日队列稳定性测试或公网渗透测试。
- 已编写 GitHub 工作流，但尚未上传执行，不等于 CI 已通过。
- 暂无自动清理；导入后章节拆分合并、角色表、读音词典、M4B、配乐混音和内置本地模型尚待开发。

下一步优先完成真实语音服务与 NAS 验收，再推进角色和音频编辑能力。

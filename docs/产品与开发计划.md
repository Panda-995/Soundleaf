# 声页：小说转有声书产品与开发计划

日期：2026-09-15 · 状态：设计阶段 · 暂定名称：声页

## 0. 项目现状与本次交付边界

当前工作目录为空，没有现有源码、部署配置或产品文档。本计划按从零建设制定。本次交付产品计划、UI/UX 规范、九页交互原型与九张 AI 界面概念图；不包含已接通的小说合成服务，也不代表完成 Docker 或真实设备验证。

## 1. 产品定位

一个可自行 Docker 部署的小说有声化 Web 工作室：小说作为项目，章节作为交付单元，片段作为最小修订单元。

核心路径：上传小说 → 校对分章 → 选择叙述模式和音色 → AI 解析并审阅 → 片段试听 → 逐章生成 → 试听校对 → 单章或批量导出。

首版优先支持个人与家庭 NAS 使用，默认一个管理员账户。数据模型预留用户归属；多人协作、在线收费平台和公共书城不进入首版。成功指标是用户能可靠完成一本书，而非生成次数。

### 可验收目标

- 20 章样本可以正确分章、逐章生成、顺序播放、分别下载。
- 只有第 8 章一个片段被修改时，仅该片段重新合成，第 8 章重新拼接；其他章节文件不变。
- 生成到一半重启容器，已完成片段保留，未完成任务恢复，不无提示地重复提交未知结果的付费请求。
- AI 不可用时，可以选择单人旁白、默认语速继续制作。
- 不要求 NAS 配有 GPU：默认云端语音引擎，后续可选本地推理。

## 3. 完整用户流程

### 首次使用

启动容器 → 创建管理员 → 选择语音服务 → 填写密钥/地址 → 获取音色 → 测试连接 → 生成一段短音频 → 进入书架。可跳过服务配置先导入小说；生成按钮需明确提示缺少配置。

### 新建有声书

1. 选择 TXT 或 EPUB，显示文件大小、名称和导入状态。
2. TXT 自动检测 UTF-8/GB18030，允许切换编码并预览；不可直接以乱码进入下一步。
3. EPUB 结合阅读顺序与目录定位正文，过滤封面和导航，内嵌文本做安全清理。拒绝受保护或无法解析的文件并说明原因。
4. 分章依据目录、中文数字章名、阿拉伯数字标题等规则；正文中的“第三章”不能仅凭子串匹配就拆分。
5. 左侧目录，右侧原文。用户可查看章长异常、拆分、合并和恢复默认；支持完全没有章节的文本按段落/目标字数辅助分章。
6. 确认书名、作者、封面与排除项，创建书籍。原文件和文本快照独立保留。
7. 挑选音色与模式。先用书中所选 100–200 字试听，提示此次合成可能计费。
8. 只对选定章节执行 AI 分析；检查建议后生成。AI 分析和正式合成是两个独立动作。
9. 可关闭浏览器，服务端任务继续执行。返回后恢复进度。

### 修正与再生成

在试听页标记问题 → 跳转对应章节/片段 → 修改朗读文本或控制参数 → 保存新版本 → 显示受影响范围 → 仅重新合成相关片段 → 重新拼接该章 → 用户切换为当前成品。

原音频不被静默覆盖。章节标记“设置已修改，音频待更新”，仍可试听旧版本，但导出必须显示版本并允许明确选择。

## 4. 页面清单与交互约定

| 页面 / 建议路由 | 核心内容 | 主动作 | 空/失败状态 |
|---|---|---|---|
| 书架 `/library` | 书封、章节完成数、最近播放、搜索、状态过滤 | 导入小说；继续制作 | 首次导入引导；搜索无结果 |
| 导入 `/import` | 文件、编码、识别目录、正文、异常提示 | 确认分章 | 乱码、超限、空文件、受保护 EPUB |
| 章节工作台 `/books/:id` | 章节表、状态、音色、时长、修改标记、批量操作 | 生成所选；试听；进入导演 | 部分完成、缺音色、音频过期 |
| AI 导演 `/books/:id/chapters/:cid/director` | 目录、原文/对话片段、角色、情绪、合成语速、停顿、版本 | 保存建议；试听选段；生成本章 | 分析失败、不确定说话人、引擎不支持 |
| 音色库 `/voices` | 来源、语言、声音特征、支持能力、收藏、统一试听文本 | 试听；应用到项目 | 服务未配置、音色已下架、试听失败 |
| 任务队列 `/jobs` | 阶段、片段计数、章节进度、已用字符、错误原因 | 暂停调度；取消；重试失败项 | 网络断开、额度不足、磁盘不足 |
| 试听 `/books/:id/listen` | 封面、章节、实际波形、段落定位、书签 | 播放；下一章；标记问题 | 未生成、音频丢失、浏览器格式不支持 |
| 导出 `/books/:id/export` | 章节选择、格式、版本、文件名预览、历史 | 创建导出包；下载 | 未生成章、过期版本、打包失败 |
| 设置 `/settings` | 语音服务、AI 服务、存储、账户、能力检测 | 测试连接；保存 | 凭据错误、服务不可达、空间不足 |

首次管理员、登录、确认费用、删除确认、快捷帮助属于附属流程，使用与设置/导入一致的表单与对话框，不新增复杂导航。原型提供首次设置与登录的表单预览；九张 AI 图覆盖九个主要工作页面。

### 页面关系

书架 → 导入 → 工作台；工作台 ↔ 导演/音色库；工作台 → 任务队列 → 试听 → 导出；全局始终可进入设置。

全局播放器切换页面不停止，只允许一个音源播放。片段试听会暂停章节播放，并保留原播放位置；结束后由用户选择是否恢复，不突然自动播放。

## 5. AI 导演设计

### 管线

规则清洗 → 章节切分 → 段落与句子切分 → AI 结构化建议 → Schema 校验 → 能力映射 → 人工审阅 → 语音片段合成 → 音频检查 → 章节拼接。

清洗版本独立于原文。去广告、替换发音和数字读法必须可见、可撤销。模型输入中的小说文字仅是数据，不得执行其中指令；模型无文件、网络或密钥工具权限。

### 建议结构

```json
{
  "chapter_id": "chapter-007",
  "source_revision": 3,
  "segments": [{
    "segment_id": "segment-018",
    "source_start": 324,
    "source_end": 348,
    "speaker_id": "narrator",
    "emotion": "calm",
    "speed": 0.95,
    "pause_after_ms": 450,
    "confidence": 0.78,
    "reason": "句尾留出停顿，保持叙述节奏"
  }]
}
```

字符位置统一以 Unicode 码点、左闭右开计算；后端验证边界且检查所有片段按顺序完整覆盖可朗读原文，没有重复或遗漏。示例数字仅说明字段。模型输出不得自行重写小说；朗读替换文本单独保存。低把握值是模型自评提示，不表示经校准的准确率；上线前在样本集评估阈值。

默认使用保守情绪，避免逐句夸张变化。语速以章级基线加片段覆盖；在相邻片段之间限制变化并允许手动锁定。停顿参数只作用于合成过程，播放器倍速仅改变听取速度，两者必须分开命名。

### 角色连续性（P1）

书籍维护角色表和别名。每章只传递必要的角色资料与前章摘要，避免整本反复发送。旁白始终有默认音色；无法确认说话人时标记“待确认”，可暂用旁白，不能随意新增角色。角色音色更换时先计算受影响片段，用户确认范围再重新合成。

### 能力映射

每个 adapter 声明语言、音色、最大文本长度、格式、采样率、speed/emotion/pause/pronunciation 能力与数值范围。UI 从服务端能力生成控件。

不支持情绪的引擎仍可朗读，但要显示“当前引擎不支持情绪控制”；不得把一个任意情绪标签当成已经生效。不支持直接停顿时可用片段间静音拼接；要注明实现方式。模型版本和音色 ID 固定写入任务快照。

## 6. 引擎与技术选型建议

默认采用云端 TTS，使 Web/NAS 主机主要负责管理、存储和拼接。首个 adapter 建议评估 MiniMax：官方 HTTP 文档提供 voice_id、speed、emotion、发音词典与音频格式示例，适合做本项目的能力验证。具体可用模型、配额、价目和音色应在实现时动态核验，不在设计中承诺固定数量或免费额度。

本地 TTS 作为 P1 可选扩展，Kokoro 是可评估候选：官方仓库提供普通话入口与 speed 参数。该证据不说明所有情绪都可控，也不证明目标 NAS 上的速度可接受。应先比较中文多音字、长句、对话稳定性，再决定是否默认提供。

AI 分析接入独立的 LLM adapter，支持自定义地址、模型和密钥。兼容接口不等于任意服务完全兼容；结构化输出、超时、上下文长度分别检测。

建议前端 React + TypeScript + Vite；后端 Python + FastAPI；SQLite 保存书籍与持久任务；本地文件系统保存原文与音频；FFmpeg/ffprobe 做音频拼接、转码与验证。这是计划选型，尚未安装或锁版本。原型采用免构建 HTML/JS，便于评审。

### 默认部署结构

```text
浏览器 → 同源 Web/API
              ├─ SQLite：书籍、片段、版本、任务、用户
              ├─ /data：源文件、文本、音频、导出
              └─ 后台工作进程 → AI/TTS → 音频处理
```

默认一个应用镜像，在容器内监督 API 与工作进程；工作进程失效须可检测，避免健康页成功而任务永远不动。低并发先不引入 Redis/PostgreSQL；如需要多个应用实例，再迁移数据库与队列。

### 持久任务与幂等

- 阶段分开：解析、分析、合成、拼接、校验、导出。
- 任务状态：queued → running → succeeded / failed / cancelled；调度暂停不等于立即中断供应商已接受的请求。
- 工作进程使用数据库事务领取任务、租约和心跳，过期租约可恢复。
- 缓存键包含文本、音色、引擎、模型版本、参数、发音词典版本；缓存引用和内容校验可追溯。
- 网络超时且不确定供应商是否已完成时，进入“结果待确认”；有供应商任务 ID 时查询恢复，没有幂等能力时不要自动无限重试，以免重复计费。
- 429/临时 5xx 有上限退避重试；401、额度不足和磁盘不足立即暂停相关队列并给出处理入口。
- 临时音频验证通过后原子改名，最后才提交成品记录。取消任务保留已完成片段，避免浪费。
- 单本同时编辑使用 revision 乐观锁；保存冲突提示比较，不以晚保存静默覆盖。

### 数据模型

User、Book、SourceFile、Chapter、TextRevision、Segment、Character、VoiceProfile、ProviderConfig、AnalysisRevision、AudioRevision、Job、JobAttempt、Export、PlaybackProgress、PronunciationEntry。

主要关系：Book 有序包含 Chapter；Chapter 包含版本化 Segment；Segment 的音频有多个不可变 AudioRevision；章节成品记录使用了哪些片段版本。导出引用确定的章节音频版本；清理时按引用与保留期处理。

### 建议 API

```text
POST /api/imports                         上传，返回后台解析任务
GET  /api/imports/:id                     分章结果与解析进度
POST /api/imports/:id/confirm             按修正结果建立书籍
GET  /api/books/:id/chapters               分页章节列表
PATCH /api/chapters/:id                   带 revision 的文本/设置保存
POST /api/chapters/:id/analyze            返回分析任务
POST /api/segments/:id/preview            返回短试听任务
POST /api/books/:id/generate              指定章节与参数快照
GET  /api/jobs/:id                        查询持久状态
POST /api/jobs/:id/cancel                 取消/停止后续片段
GET  /api/events                          SSE 状态通知，可断线补拉
GET  /api/audio/:id                       鉴权、Range、正确媒体类型
POST /api/books/:id/exports               指定章节版本，异步打包
GET  /api/exports/:id/download            鉴权下载
```

所有 book/chapter/audio ID 查询均校验用户归属；任务状态不能只存于浏览器或 SSE 连接。

## 7. 音频工程

长章按句界和引擎限制拆成片段，不能在固定字符位置硬切。语义上下文可用于 AI 分析，但不能被重复送入实际发声文本。音频统一内部 PCM 中间格式后再拼接，输出编码一次；避免每次修改反复有损转码。

章节边界与片段衔接保留可控停顿。默认不要使用会吞字的跨片段交叉淡化；消除点击声要先检查边界与静音。响度目标与 true peak 作为配置策略，以样本试听确定，不硬套音乐母带参数。

质量检查：文件可解码、时长非零、片段数量完整、缺失音轨、削波与异常静音；可选回转录比对漏字，但 ASR 本身会出错，结果应供人工复核而非自动删除内容。

试听波形来自真实音频峰值数据。没有词级时间戳时，只实现片段高亮；不得用估算进度伪装精确逐字同步。播放记忆包含 audio_revision_id，版本变化时重新定位到相近片段并提示。

## 8. 导出约定

- 每章可下载 MP3 或 WAV；ZIP 按排序后的章号保存，例 `雾海来信/007_灯塔来客.mp3`。
- 文件名去除非法字符与路径穿越，重名加稳定后缀，章号按总章数补零。
- 导出固定版本快照；打包时继续编辑不会改动这次包内容。
- 仅有部分章生成时可“仅导出已完成章节”，先清楚列出遗漏，不能显示“全书导出成功”。
- 提供书名、作者、章名、朗读音色、生成时间与参数清单。封面默认使用用户文件或项目内置图案。
- ZIP 异步生成并支持失败重试；成品提供鉴权下载和过期清理设置。WAV 体积通常更大，显示实际或估算体积并标注。
- M4B 和字幕属于后续版本；可用于设计扩展，首版不放可点击的假功能按钮。

## 9. Docker 与运维计划

默认体验目标：一个镜像、一个数据挂载、一个 Web 端口；不要求 GPU，不默认对外开放数据库。

### 容器接口草案（尚无可部署镜像）

```yaml
services:
  app:
    image: <待发布的声页镜像>:<固定版本>
    ports:
      - "127.0.0.1:8780:8780"
    volumes:
      - ./data:/data
    environment:
      TZ: Asia/Shanghai
    restart: unless-stopped
```

上例仅用于接口评审，不能直接运行。默认回环绑定适合本机与反向代理；需要家庭局域网访问时可明确改为 `8780:8780` 并完成管理员设置。密钥在 Web 设置页输入，服务端加密保存；主密钥存储于独立受限文件，备份需包含且妥善保护。迁移时主密钥丢失会使已存凭据不可解密。

- 容器使用非 root 用户，挂载目录在启动时校验可写，给出 NAS 权限处理提示。
- `/data` 必须包括 SQLite、原文件、音频、导出和模型缓存；临时目录配额受控。
- SQLite 位于本地磁盘文件系统；不默认支持跨机器共享网络盘数据库。
- 备份使用 SQLite backup API 或停止写入后快照，不能只复制活跃数据库主文件而漏掉 WAL。
- `/health/live` 表示进程存活；`/health/ready` 检查数据库与目录，另报 worker 心跳。云端供应商断网不造成容器重启循环。
- 重建容器保留书籍、已完成任务与播放进度；升级前自动迁移检查及备份。
- 发布阶段分别验证 linux/amd64、linux/arm64，尤其 FFmpeg 与本地推理依赖；构建成功不等于 NAS 实测通过。

## 10. 非功能需求

初始限制建议：TXT/EPUB 单文件 50MB；解压总量 200MB、文件数 5000；支持 1000 章与百万字长书。以上为保护性产品默认值，需压测后校准；超限提示拆分或管理员调整。解析与合成都在后台，章节列表分页/虚拟化，不能一次渲染整本。

性能预算目标：典型局域网缓存后章节切换 <300ms；任务状态更新约 1–2 秒；长任务不阻塞 API。TTS 耗时显示基于历史实测的区间，没有样本时显示“正在估算”，不承诺固定实时倍率。

登录使用安全会话、合理限流、防 CSRF、退出失效。上传验证内容与扩展名，防 EPUB 解压穿越与压缩炸弹；不执行 EPUB 脚本、不加载远程资源。供应商地址仅管理员可配置，限制任意 URL 访问；允许本地模型地址是显式选项，阻止云元数据地址。导出与日志不包含密钥、完整小说内容或个人凭据。

默认文本与音频留在挂载目录；启用云 AI/TTS 时在设置中明确说明相应文本会发送至所选服务。只处理用户有权使用的文件，不内置抓取收费小说或绕过 DRM 功能。

## 11. 开发顺序与完成门槛

工期为单人全栈开发的初步估算，需通过第一阶段真实语音验证再调整；合计约 6–8 周，不是交付承诺。

| 阶段 | 工作与预计投入 | 完成门槛 |
|---|---|---|
| 0 验证 | 2–3 天：接一个真实引擎，中文样本与成本验证 | 长句、数字、多音字、不同情绪各有实听记录 |
| 1 骨架 | 1 周：账户、导入、分章、书架、存储 | 重启保留数据，异常文件有明确处理 |
| 2 闭环 | 1–1.5 周：音色、持久任务、单章试听、MP3/WAV/ZIP | 20 章样本全流程可完成 |
| 3 AI | 1–1.5 周：结构化分析、审阅、局部重做 | 无漏段重复，AI 失败可回退，修改范围正确 |
| 4 体验 | 1 周：九页实现、响应式、版本提示、播放连续性 | 1440/1024/390 宽度无核心阻塞，键盘流程可用 |
| 5 发布 | 1 周：容器、多架构、恢复、备份、真实 NAS 验证 | CI、镜像、健康、权限、重启恢复均有记录 |

P1 多角色识别、复杂同步、本地推理与 M4B 独立排期，不挤入 P0 稳定性工作。

### 必测场景

1. UTF-8/GB18030、无章名、重复章名、空章、超长章、EPUB 目录异常。
2. 小模型不返回 JSON、幻觉改写、片段漏字、角色无法识别。
3. 密钥失效、429、供应商超时且结果未知、磁盘写满。
4. 中途杀 worker、重启整个容器、连续重复点击生成、并发保存冲突。
5. 修改单句后其他章节 hash 不变；旧版本仍可试听与导出。
6. 单章 Range 拖动、切页不停播、试听与播放器互斥、移动端控制可用。
7. ZIP 顺序、Unicode 名称、部分完成提示、WAV 可解码、时长与拼接一致。
8. 未登录访问音频失败、跨用户资源隔离、上传路径穿越被拒绝、备份恢复成功。

# 声页 v1.2.0

本次增加 CPU 本地语音合成与模型管理，并修复未保存编辑、成品更新状态、重复操作及任务恢复等问题。

## 新增与改进

- Kokoro 内置音色、ZipVoice 参考音频音色克隆、模型下载与管理；可切换云端与本地语音引擎。
- 保存期间继续编辑不会被旧响应覆盖，忽略 AI 分段建议保留草稿。
- 修复生成期间修改中文读音词典或角色音色后的过期判断，避免混合旧配置的成品被误认作最新。
- 重复 AI 分章能显示新结果，切书会取消旧音频的在途加载。
- 远端请求状态持久化，重启后对未知结果进入待确认；封面提交与清理共享锁。
- 改善手机设置标签，修正对比度审计，补充回归测试和统一版本门禁。
- 绿联上架描述同步真实功能，说明云端费用、本地模型下载及设备能力边界，不作第三方授权、合作或认证宣称。

## 安装资源

- GHCR 镜像：`ghcr.io/panda-995/soundleaf:1.2.0`，支持 `linux/amd64` 与 `linux/arm64`；`latest` 指向本次版本。
- 绿联 UGOS Pro UPK：按 NAS 架构选择 amd64 或 arm64，套件版本 `1.2.0.0003`。
- `Soundleaf-1.2.0-deploy.zip`：版本固定的 Compose、配置示例、部署说明、更新日志及绿联描述。
- `SHA256SUMS`：Release 安装资源校验值。Source code 由 GitHub 提供。

## 升级

升级前停止实例并完整备份原数据目录，包括 `studio.sqlite3`、`secret.key`、WAL/SHM 与文件子目录。保持原挂载目录和访问权限，再更新镜像或安装新 UPK；不要同时运行两个实例共用数据。

v1.1.0 数据采用增量迁移，旧账号、加密设置、书籍、音频、封面、角色、词典、播放进度、问题标记与导出均可保留。新增的任务请求状态不需要重新导入。中断且可能已计费的远端任务需要用户确认后再重试。

本地模型需另外下载。云端合成、AI 分析和封面生成使用用户自配接口，可能产生费用。模拟服务集成验证不等同于真实付费服务音质或 NAS 实机验证。

## 逐项修复

| 编号 | 实现 | 验收 |
| --- | --- | --- |
| A1 | 导演页用本地编辑序号保护保存后的新输入；存在后续编辑时只更新服务端 revision，保留草稿和未保存状态 | 延迟保存期间继续输入，内容保留；再次保存使用最新 revision 并成功清除 dirty |
| A2 | 忽略 AI 分段建议只合并 `restructure:null`，不重新加载并覆盖整章 | 未保存正文保留，建议消失，保存按钮仍可用 |
| A3 | 整章和局部生成完成时同时核对词典、角色版本；生成中换音色产生的片段失效标记不会被清空 | old/old 生成后改为 new；只重做第一句时导出 409，第二句也重做后才为 200 |
| A4 | 发布版本由 `pyproject.toml` 读取；校验前端清单、锁文件、UGOS 元数据、镜像引用及 Release tag；锁文件和 UGOS Compose 同步到 1.2.0 | 当前元数据通过；错误 tag、锁文件漂移被拒绝；`GITHUB_ENV` 输出 APP_VERSION=1.2.0；工作流 YAML 可解析 |
| A5 | 持久化 `jobs.remote_inflight`，远端请求前提交标记；未知结果重启后进入 needs_review；兼容旧阶段名及其初始阶段 | 五类 AI 调用和远端语音合成均在请求前有标记；替换显示阶段文字后仍进入 needs_review；五种旧 AI 阶段均受保护 |
| A6 | 直接比较词典内容，消除中文 JSON 转义差异；词典更新与失效标记在同一事务提交 | 稳定中文词典逐段重做后能解除标记；重做期间再改词典仍拦截导出，最终读音重做后恢复 |
| A7 | AI 分章详情刷新状态绑定任务 ID，新任务重置详情刷新标记 | 同页第二次识别完成后显示完成状态和新分章预览 |
| A8 | 每次切书均重置播放器并取消在途请求，包括首次音频元数据尚未加载的情况 | 延迟旧音频元数据，切到第二本书后旧响应不会载入音频 |
| A9 | HTTP 上传、AI 封面、资料生成封面与封面对账共用 `Store.cover_lock`，覆盖文件写入到引用提交及替换清理 | 强制上传/清理交错后封面存在且 GET 为 200；真正孤儿文件仍被回收；现有封面替换测试通过 |
| A10 | OKLCH 转换先对 LMS 分量立方，再乘 RGB 矩阵；新增彩色向量与 4.5:1 阈值测试 | 红绿蓝参考向量、黑白和灰色阈值测试通过；双主题彩色 token 与 Chromium Canvas 参考比值误差低于 1.5% |

手机设置标签改为保持单行并允许横向滚动。390px 页面实测六个标签均不折行，最后的“关于”标签可以滚动到并选中；页面没有横向溢出。

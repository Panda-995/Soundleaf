自托管 · 开源 · 小说有声化工作室

让文字，被听见。

声页（Soundleaf）是把一本小说逐章做成有声书的工作室：自动分章、角色配音、AI 朗读建议、 逐段精修，最后导出带章节导航的 M4B。它运行在你自己的机器上—— 文字、声音和数据，都留在你手里。

为什么是声页

像工作室一样制作，
而不是一键生成

一键生成的有声书往往「能听」，但不耐听。声页把制作权交回给你：每一章、每一段、每一个角色的声音，都可以被审阅和调整。

01

逐章工作室，
改一句只重做一句

在章节工作台里逐段编辑文本、音色、语速、情绪与停顿。改完某一句，只重新合成那一段并就地拼回章节音频，其余部分一动不动。

↳ 章节工作台 · 片段级重生成 · 任务队列

02

让每个角色，
各有其声

合成时自动拆分混合片段：引号内的对白用角色音色，引号外的叙述回到旁白。角色库统一管理全书角色与音色绑定，换声后受影响章节批量更新。

↳ 角色库 · 引号边界拆分 · 书级音色绑定

03

AI 出建议，
你来拍板

AI 导演标注每段说话者，建议情绪、语速与停顿；划选正文即可修正多音字读音。原文一字不改，建议可采纳、可修改、可撤回。

↳ AI 导演 · 读音词典 · 建议先审阅后应用

04

数据与声音，
都留在你手里

单容器、单数据目录，安家在 NAS 或任意 Docker 主机。不配置云端也能用 CPU 本地合成；云端密钥加密保存，全程无 GPU、无特权模式。

制作流程

从一本小说，到一部有声书

四步走完一本书：每一步都可以停下来检查，先试听、后批量，不满意的片段随时单独重做。

  1. 01

    导入与分章

    上传 TXT 或未加密 EPUB，自动识别章节边界；可编辑、拆分、合并、排序与排除章节，原始文件始终保留。

    对应页面：导入 · 章节工作台
  2. 02

    排角色 · 定声音

    在角色库登记人物与台词量，一键绑定音色；AI 优化分段把对白与叙述拆成独立片段，并标注每段说话者。

    对应页面：角色库 · AI 导演 · 音色库
  3. 03

    逐段精修 · 先听后批量

    用读音词典修正多音字与人名地名，为片段挑选 21 种情绪风格与语速；先试听确认，再逐章或批量生成。

    对应页面：AI 导演 · 任务队列 · 试听
  4. 04

    导出成品有声书

    导出单文件 M4B：AAC 音轨 + 章节导航 + 书名 / 作者 / 封面元数据；也可以逐章 MP3 / WAV 打包 ZIP。

    对应页面：导出

声音与 AI

声音在你手里，
AI 只是副驾驶

两种引擎随意切换，书籍音色绑定会被记住；每段合成后都对齐统一响度，角色之间不再忽大忽小。

云端引擎

MiniMax 与兼容服务

支持 MiniMax 官方接口，以及任何兼容 /audio/speech 的自选服务。音色同步、收藏、短试听；限流等瞬时拒绝自动重试，失败会定位到具体片段。

本地引擎 · 离线

Kokoro 合成 + ZipVoice 克隆

下载 Kokoro 模型后用 CPU 即可合成，内置 103 个中英文音色；也可以用 ZipVoice 加一段参考音频，创建你自己的克隆音色。无需任何云端密钥。

读音词典按书存储「词 → 读法」，合成前自动应用、原文不改；修正过的词在脚本里高亮，随时可以撤销。

部署

一行命令，安家在你的服务器

没有 GPU 要求，没有特权模式，不挂载 Docker socket。amd64 / arm64 双架构镜像发布在 GHCR，绿联 UGOS Pro 提供一键安装包。

Docker 一行启动

先创建一个普通可写目录作为数据目录，再启动容器。访问 8780 端口，默认账户 admin / admin，首次登录会要求修改密码。

docker run -d --name soundleaf -p 8780:8780 \
  -v /path/to/data:/data \
  ghcr.io/panda-995/soundleaf:latest

绿联 UGOS Pro

从 Releases 下载 UPK 安装包（amd64 / arm64 双架构），在 UGOS Pro 应用中心手动安装，安装向导中选择数据文件夹即可。

常见问题

开始之前，你可能想知道

需要什么样的硬件？

不需要 GPU。使用云端语音服务时，一个普通容器就够了；使用本地 Kokoro 引擎时，CPU 即可合成，速度取决于设备性能。长篇制作前请预留磁盘空间存放音频与缓存。

必须配置云端 API 密钥吗？

不必须。下载本地模型后，无需任何密钥即可合成；AI 分析、AI 封面是可选增强，不配置也完全可以手动制作。云端语音、AI 与生图服务使用你自己的接口与账号，费用由你的账号承担，软件不附带任何额度。

支持哪些格式？

导入支持 TXT 与未加密 EPUB。导出支持带章节导航与封面元数据的单文件 M4B（AAC），以及逐章 MP3 / WAV 打包的 ZIP。

我的小说会被上传到别处吗？

所有数据都在你自己的数据目录里。只有当你配置并使用云端服务时，所选文本才会发送给你配置的那个服务；本地合成全程不经过外网。云端密钥在服务端加密保存，不会回传浏览器。

可以多人一起用吗？

声页目前按单账户工作室设计，适合个人作者或家庭 NAS 使用；配乐混音与多用户协作尚未实现。应用必须单进程、单副本运行，不要多个容器共享一个数据目录。

对生成的音质有什么承诺？

音质取决于你选择的语音服务或本地模型。声页能承诺的是工程侧的稳定性：响度归一化减少角色间音量跳变、瞬时限流自动重试、失败定位到具体片段、改一句只重做一句，不让你为一句话重做整本书。
